encryption:
At transit:
- React to backend should use HTTPS
- backend to AllegroGraph should also be protected, ideally internal network/VPN/TLS

At rest:
AllegroGraph
- stores RDF structure
- stores public/non-sensitive fields as normal RDF
- stores sensitive fields encrypted

Backend
- authenticates users
- checks permissions
- decrypts sensitive fields only for allowed users
- encrypts sensitive fields before insert/update

React
- never sees encryption keys
- only displays what backend returns

Data needed for search/filtering/linking/reasoning → store as RDF
Sensitive free-text/source/person-identifying data → encrypt field-level
Access decisions → backend only
Keys → never in React
